Widget demo

Deze pagina laadt de chatbot-widget lokaal. Start eerst de API (uvicorn api:app --reload) en open deze pagina via een lokale webserver, bijvoorbeeld:

python -m http.server 8000 → open http://127.0.0.1:8000/widget/demo.html

Klik rechtsonder op het chat-icoon en stel een vraag over een van de projecten in content/.
